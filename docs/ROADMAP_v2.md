# 專案發展藍圖

本文檔規劃記帳系統的發展目標，以**使用者體驗（UX）優先**為核心原則。

> 📌 注意：本規劃不設定具體時間表，項目實施順序取決於實際需求與資源。

---

## ✅ 已完成摘要

> 2026-03-21 以前完成的主要功能。

| 類別 | 完成項目 |
|------|---------|
| 安全性 | XSS/CSRF/NoSQL 防護、速率限制、bcrypt 密碼、JWT 認證 |
| 效能 | DB 複合索引、gzip 壓縮、TTL 快取、JS minify、分頁機制（後端） |
| 前端架構 | ES6 模組化（18 個模組）、EventBus 解耦、PWA / Service Worker |
| 核心功能 | 記帳 CRUD、分類系統、定期收支、預算管理、收支分析 |
| 資料管理 | CSV/Excel/JSON 匯出、JSON 備份還原 |
| 測試 | 290 個後端測試（85.03%）、26 個 E2E 測試（Playwright） |

## 🔴 第一優先：UX 快速改善

> 低難度、高可見度，直接影響日常使用體驗

### 1. Empty States（空狀態提示）
**重要性**: ⭐⭐⭐⭐⭐ | **難度**: ⭐

- [ ] 記錄頁無資料 / 篩選無結果時，顯示友善提示與建議操作
- [ ] 分析頁首次載入無資料時，顯示引導訊息
- [ ] 定期收支列表空白時，顯示「尚無設定」提示

---

### 2. Loading 狀態指示
**重要性**: ⭐⭐⭐⭐⭐ | **難度**: ⭐

- [ ] `loadRecords()` 期間顯示骨架卡片（Skeleton）或 Spinner
- [ ] 統計卡片載入中顯示佔位動畫，而非直接顯示 $0
- [ ] 分析圖表載入中顯示遮罩，避免閃爍

---

### 3. 即時搜尋（去掉「查詢」按鈕）
**重要性**: ⭐⭐⭐⭐⭐ | **難度**: ⭐

- [ ] 關鍵字輸入後 debounce 300ms 自動觸發搜尋
- [ ] 移除手動點擊「查詢」按鈕的需求
- [ ] 篩選條件變更時同樣即時觸發

---

### 4. 手機版 Analytics 頁響應優化
**重要性**: ⭐⭐⭐⭐ | **難度**: ⭐

- [ ] 三欄統計卡片在行動版（< 640px）改為 1 欄堆疊
- [ ] 確保數字不被截斷，字型大小可讀

---

### 5. 清除篩選按鈕
**重要性**: ⭐⭐⭐⭐ | **難度**: ⭐

- [ ] 篩選列右端新增「清除全部」按鈕
- [ ] 有篩選條件時才顯示（條件清空後自動隱藏）

---

### 6. 操作成功回饋
**重要性**: ⭐⭐⭐⭐ | **難度**: ⭐

- [ ] 新增記錄成功後顯示 Toast（已有 `showToast()` 可直接呼叫）
- [ ] 編輯/刪除記錄後顯示對應 Toast
- [ ] 備份還原成功後顯示確認訊息

---

### 7. 日期選擇行動版優化
**重要性**: ⭐⭐⭐ | **難度**: ⭐

- [ ] 行動版（touch device）改用 native `<input type="date">`
- [ ] 桌面版維持現有 UI

## 🟠 第二優先：UX 功能完善

> 難度中等，顯著提升分析與操作深度

### 8. 趨勢折線圖實作
**重要性**: ⭐⭐⭐⭐ | **難度**: ⭐⭐⭐

- [ ] 支援週/月切換，顯示收支趨勢線

---

### 9. 前端分頁 UI
**重要性**: ⭐⭐⭐ | **難度**: ⭐⭐

- [ ] 後端 `/records` 已回傳 `total` / `total_pages`，前端補加翻頁元件
- [ ] 翻頁按鈕：上一頁 / 下一頁 + 當前頁碼
- [ ] 或改為「載入更多」infinite scroll

---

### 10. 分類管理介面
**重要性**: ⭐⭐⭐ | **難度**: ⭐⭐⭐

- [ ] 設定頁新增「分類管理」區塊
- [ ] 支援自訂分類顏色（色票選擇）
- [ ] 支援分類圖標選擇（emoji 或 icon）
- [ ] 支援刪除自訂分類（系統預設分類不可刪）

---

### 11. 快速記帳流程優化
**重要性**: ⭐⭐⭐ | **難度**: ⭐⭐

- [ ] 記帳表單記憶上次使用的類別（localStorage）
- [ ] 金額輸入框自動聚焦（頁面切換到「記帳」時）
