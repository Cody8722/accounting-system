# 專案發展藍圖

本文檔規劃記帳系統的發展目標，以**使用者體驗（UX）優先**為核心原則。

> 📌 注意：本規劃不設定具體時間表，項目實施順序取決於實際需求與資源。

---

## ✅ 已完成摘要

> 2026-03-21 以前完成的主要功能。

| 類別 | 完成項目 |
|------|---------|
| 安全性 | XSS/CSRF/NoSQL 防護、速率限制、bcrypt 密碼、JWT 認證 |
| 效能 | DB 複合索引、gzip 壓縮、TTL 快取、JS minify、分頁機制（後端） |
| 前端架構 | ES6 模組化（18 個模組）、EventBus 解耦、PWA / Service Worker |
| 核心功能 | 記帳 CRUD、分類系統、定期收支、預算管理、收支分析 |
| 資料管理 | CSV/Excel/JSON 匯出、JSON 備份還原 |
| 測試 | 290 個後端測試（85.03%）、26 個 E2E 測試（Playwright） |

### 2026-03-21 之後（前端整個重寫為 `frontend/v2/`，詳見 [CHANGELOG.md](../CHANGELOG.md) `[1.0.0]`）

| 類別 | 完成項目 |
|------|---------|
| 前端架構 | `frontend/js-refactored/` 整個換成 `frontend/v2/`（純 ES Modules、手機/電腦響應式殼層，無 build step） |
| 電腦版體驗 | 概覽儀表板（KPI 卡 + 卡片釘選）、預算桌面雙欄版型 |
| 資金錢包 | 錢包分離（`wallets` 集合）、帳戶×位置雙維度、受限資金、內部轉移、資金流向樹視覺化 |
| 離線 / 同步 | 離線登入與瀏覽、離線寫入佇列 + 回連自動同步、輕量更新檢查（data-version 閘門） |
| 記帳照片 | 拍照/選圖上傳、事後補充/刪除、離線相片佇列、跨記錄照片瀏覽 |
| 測試 | 後端測試增至 582 個；E2E 改用 `frontend/tests/e2e/v2/`（20 個測試）；前端單元測試改用 Node 內建 `node --test` |

下方「第一優先」「第二優先」清單是 2026-03-21 當時規劃的待辦，其中多數項目已隨 v2 重寫一併完成（逐項標記見下），尚未逐項覆核的請視為需要重新確認現況，不要直接假設仍是待辦。
