# 電腦版概覽儀表板 — 釘選式互動原型

`pin-dashboard-prototype.html` 是**電腦版概覽頁「卡片釘選（Pin）」互動**的獨立原型（自帶假資料，直接用瀏覽器開即可，不需後端）。

目的：把互動手感先在原型裡打磨到滿意，再整合進正式的 `frontend/v2/js/dashboard.js`。這份是**當前快照**，供設計端接著細修視覺手感，不是最終定稿。

## 互動概念

參考 Google Meet「釘選」多人視訊：
- **平常**：4 張卡（分類佔比 / 支出趨勢 / 最近交易 / 預算概覽）2×2 平均分配。
- **釘選某張**：該張放大成主舞台，其餘 3 張縮成右側縮圖列。
- 外框高度固定（整頁鎖定視窗高度、不滾動），釘選只重新分配內部空間。
- 縮圖為精簡摘要；釘選態提供「查看完整頁面」連結，導向既有的統計/明細/預算頁做深入分析。

## 已定案（這份快照採用的做法）

- **一屏鎖定**：整頁 = 視窗高度的 flex 直欄，永不滾動；卡片區塊 `flex:1` 吃滿剩餘空間。
- **只有主角飛**：只有被點的卡做空間動畫（FLIP 縮放/移動）；其餘 3 張不飛（隱藏→於定位淡入），避免空白卡移動路徑交錯重疊。
- **模糊過場**：框架縮放期間，主角內容維持可見但 `filter: blur()`（非隱藏），框架到位後模糊退去、內容切換成該階段樣子（縮圖版/完整版）。
- **標題列反向補償**：主角縮放時，標題文字/圓點/釘選 icon 逐元素套 `1/scale`（rAF 逐格），維持固定字級不被拉伸，且位置隨卡片 FLIP 平滑移動。
- **節奏**：正常 0.4s（`easeInOutSine`）。工具列「慢動作」以 0.4s 為基準 1×/2×/4× 放慢，方便觀察。
- **動畫開關**：工具列可切「動畫 開/關」直接對比跳變 vs 動畫（原型預設一律播動畫，避免沙箱 `prefers-reduced-motion` 把動畫關掉；正式版會改回尊重該設定）。

## 仍開放、想交給設計端把關的細節

- **模糊強度**：目前 `blur(6px)`，可再調（太糊 → 3–4px；不夠感 → 8–10px）。
- **A→B 直接切換釘選**：目前舊的 A 是配角 → blink（淡出後於縮圖列淡入），而非平滑縮小。是否要讓切換時「新釘 B」與「舊釘 A」都當主角平滑縮放。
- **節奏微調**：0.4s 是否合適，或再快/慢。
- **配角淡入**：3 張縮圖目前是單純淡入，是否也要「模糊→清晰」materialize。

## 整合注意（未來套進 dashboard.js 時）

- 正式版須**改回尊重 `prefers-reduced-motion`**（原型為了展示而強制播動畫）。
- 真實資料是動態高度，需再驗證縮圖精簡與 overflow 行為。
