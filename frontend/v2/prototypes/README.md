# 電腦版概覽儀表板 — 釘選式互動原型

`pin-dashboard-prototype.html` 是**電腦版概覽頁「卡片釘選（Pin）」互動**的獨立原型（自帶假資料，直接用瀏覽器開即可，不需後端）。

**目前狀態：Claude Design 打磨定案版（v2）。** 由 Claude Code 接手整合進正式的 `frontend/v2/js/dashboard.js`。

## 互動概念

參考 Google Meet「釘選」多人視訊：
- **平常**：4 張卡（分類佔比 / 支出趨勢 / 最近交易 / 預算概覽）2×2 平均分配。
- **釘選某張**：該張放大成**上方主舞台（滿版、最大寬 1040px 置中）**，其餘 3 張排成**下方縮圖列**。
- 釘選時上方 chrome（頁首標題＋KPI 列）**主動收合變小**，把高度讓給主角卡片，讓中間真的變大（不是把 deck 硬塞進固定殘餘空間）。
- 外框高度固定（整頁鎖定視窗高度、不滾動）。
- 縮圖為精簡摘要；釘選態提供「查看完整頁面」連結，導向既有的統計/明細/預算頁做深入分析。

## 定案的動畫架構（v2 打磨版）

**核心：單一 `requestAnimationFrame` 迴圈、單一 eased progress 驅動全部**（不再有多條 CSS transition 時間軸，從根本消除文字殘留晃動）：

- **全部四張卡都做 FLIP** 空間動畫（允許互相交錯/重疊）；使用者點的那張為焦點卡壓最上層。
- **失焦模糊**：`.cbody` 逐幀 `filter: blur()`，峰值 **10px**，用 `sin(progress·π)` 曲線 → 移動最快的瞬間最模糊，像鏡頭追焦。
- **標題列改用「clone 疊層」而非反向補償**：把 `.chead` clone 一份，只用 `left/top/width/height` 真實版面屬性平移（完全不用 scale），字級/圓點/icon 全程原生渲染、不失真不跳動。
- **字級/圖示尺寸逐幀插值**（font-size、donut svg、交易 icon），跟外框動畫共用同一 eased，避免結束那一刻彈一下。
- **骨架佔位圖**：模糊峰值時真實內容淡出、對應形狀的骨架色塊淡入（每張卡各自的骨架，不共用樣板）。
- **chrome 收合**同樣進同一個 rAF 逐幀（font-size/padding/max-height 真實屬性插值 + 失焦模糊），跟卡片同幀完成。
- **節奏 0.4s**（`easeInOutSine`）；縮圖列/chrome 用 `eased^1.7` 落後曲線，避免比主角早定位完成。
- 動畫期間把 `.deck` `position:fixed` 釘死在量測到的最終矩形，避免 chrome 收合牽動 deck 位置造成標題疊層對不上。

## 原型專屬、整合時要處理掉的東西

- **工具列**（動畫開關 / 慢動作 1×/2×/4× / 重置 / 主題）是診斷用，正式版不保留（主題另由 v2 既有 `theme.js` 管）。
- **強制播動畫**：原型 `animEnabled=true` 忽略系統設定。**正式版須改回尊重 `prefers-reduced-motion`**（reduce 時走無動畫的直接切換分支）。
- **假資料**：donut / spark / 交易 / 預算都是寫死的；正式版接 `dashboard.js` 既有的 API 資料與真實 DOM。
- **「查看完整頁面」**：正式版改為 `emit('nav', '統計'|'明細'|'預算')` 導向既有頁。
- 真實資料是動態高度／筆數，需再驗證縮圖精簡與 overflow 行為。
